# 李磊 LI LEI - 个人作品集

面向 AI 产品负责人岗位的单页个人作品集，展示已落地产品、研究实践、设计经历与个人介绍。

## 网站结构

- `index.html`：页面内容与语义结构
- `site.css`：视觉系统与响应式布局
- `site.js`：首屏粒子动效、移动导航与作品轨道交互
- `material/portfolio-2026/`：当前页面使用的图片与简历文件

## 本地预览

网站不需要构建工具。在仓库根目录启动静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000/
```

## 部署

这是纯静态网站，可部署到 EdgeOne Pages、GitHub Pages、Netlify 或 Vercel。

EdgeOne Pages 推荐配置：

- 生产分支：`main`
- 构建命令：留空
- 输出目录：`.`
- 安装命令：留空

自定义域名：`www.lilei.hk`
